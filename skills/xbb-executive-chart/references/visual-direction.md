# 清晰证据

图的视觉重心来自事实之间的距离。以纸白为底、墨色为骨架，让比较关系自然成为第一眼看到的内容。空白围绕最值得注意的发现展开；标题、图形与来源共享明确的对齐线，像经过细致编辑的财经版面。

颜色承担定位作用。深青指向正在讨论的对象，灰青承载背景比较，少量蓝色与赭色区分真实组成。精细打磨每处对比度，避免颜色数量与装饰强度抢走数值的意义。低排名本身不被涂成风险红色。

文字采用清楚的中文无衬线，数字采用稳定的等宽数字间距。关键发现拥有标题级分量，数值紧邻对应对象；每处间距和基线都经过精确校准。长名称通过换行获得空间，口径限制完整保留。

几何形状服从真实尺度。排名从零起算，折线保留观测到的转折，构成保留同一分母，阶段宽度直接对应当期数量。制作的精度体现在难处：相邻标签避让、细小构成不塞字、接近零的真实值不消失、没有证据的位置不添加判断。

成图在完整尺寸与手机宽度下反复检查。精心打磨已有元素的大小、间距与层级，让读者先看到发现，再找到支持它的数字，最后读取必要范围。画面始终服务于这个阅读顺序。
