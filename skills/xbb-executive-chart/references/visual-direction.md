# 清晰证据

图的视觉重心来自事实之间的距离。以纸白为底、墨色为骨架，让比较关系自然成为第一眼看到的内容。空白围绕图形和数值展开；标题、图形与来源共享明确的对齐线，像经过细致编辑的财经版面。

颜色承担定位作用。深青指向正在讨论的对象，灰青承载背景比较，少量蓝色与赭色区分真实组成。精细打磨每处对比度，避免颜色数量与装饰强度抢走数值的意义。低排名本身不被涂成风险红色。

文字采用清楚的中文无衬线，数字采用稳定的等宽数字间距。每个分析分区有清晰的问题标题、实际图形、精确读数和A—D可验证证据注释；主发现醒目，其余证据补充差异、变化或集中度。数值紧邻对应对象，百分数、单位和引用标签不拆散，长名称合理换行，口径限制完整保留。

几何形状服从真实尺度。排名从零起算，折线保留观测到的转折，构成保留同一分母，阶段宽度直接对应当期数量。制作的精度体现在难处：相邻标签避让、细小构成不塞字、接近零的真实值不消失、没有证据的位置不添加判断。

综合图使用统一总标题、阅读目录和编号，按用户问题顺序排列不同子图；避免重复完整图头图尾和同数据换标题。成图在完整尺寸与390px手机宽度下实际检查，先确认问题全部覆盖与计算正确，再检查标签避让、重点、字体、换行和必要范围。
