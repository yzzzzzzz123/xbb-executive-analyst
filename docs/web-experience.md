# 受邀客户网页体验

经营查询采用完整能力模式：模型自主选择数据域、指标、比较与下钻，不以提问关键词、固定指标、公司名称字符串或每轮四次调用限制业务分析。可省略指标投影读取完整数据域；“上个月呢”等追问沿用有效主题并重新取数。访问码、集团只读授权、会话隔离和客户网页工具保护不变。

在已配置模型登录和销帮帮只读凭据的同一 Windows 用户下运行：

```powershell
cd D:\codex\xbb-executive-analyst
npm run web:start
```

脚本启动独立网页服务和 Cloudflare 临时 HTTPS 入口，输出体验链接及随机访问码。客户在自己的浏览器打开链接并输入访问码，即可查看集团全部公司的只读数据。不同浏览器的会话独立，支持连续追问、停止、经营图放大及下载。模型与取数沿用现有真实链路，不需要客户安装软件或登录 Codex。

- `npm run web:status` 查看当前链接和就绪状态；`npm run web:stop` 关闭本次网页及隧道。企微机器人独立运行。
- `npm run web:local` 只开本机页面，便于调试；切换到外网前先停止本机实例。
- 已有配置的后台服务可通过 `Start-ScheduledTask -TaskName 'Codex-XBB-Executive-Analyst-Web'` 恢复，沿用现有访问码及其有效期；隧道重新建立时会生成新链接，使用 `npm run web:status` 获取。不要用 `web:start` 恢复需要保留访问码的部署。
- 计划任务部署应配置失败后每分钟重试（本机为 20 次）。网页或隧道异常退出时，监督进程以非零状态退出，允许计划任务重启整个入口；手动 `web:stop` 正常退出，不触发失败重试。仓库外的 `web/supervisor.jsonl` 记录故障阶段及退出码，不记录访问码、聊天或业务数据。
- 每次通过 `web:start` 新建体验会生成新的链接和访问码；计划任务恢复已有配置时只更换链接。访问码有效期七天，登录最长八小时；配置只保存码的 SHA-256，不保存明文码。遗失访问码可停止后用 `web:start` 新建体验。
- 配置、原生 Thread 状态、进程状态和日志位于 `%LOCALAPPDATA%\Codex\xbb-executive-analyst\web`，不进入仓库。修改授权或禁用访问码后须重启服务才生效。访问码只发给获邀客户；网页没有公开管理接口。
- 电脑休眠、关机或断网期间不可访问。[Cloudflare 临时隧道](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/) 用于体验，不保证可用性；页面使用短轮询，适配其不支持 SSE 的限制。

网页只监听 `127.0.0.1:8091`。访问码验证、会话 Cookie、CSRF、请求频率/并发/大小限制、图片归属和取消均在服务端执行。网页模型客户端额外关闭本机命令及继承的 MCP、插件和连接器，不允许客户读取部署电脑的其他文件。页面不引入第三方脚本、分析埋点或浏览器本地聊天存储；刷新只恢复最近一次问答，模型连续对话仍由原生 Thread 持有。答复与图片仅短暂缓存在服务内存中供交付，退出或会话过期时清除。

该入口是借助当前电脑的客户体验版。浏览器关闭不主动停止已提交的分析；点“停止分析”、退出会取消当前任务。关闭服务使用上述本地命令，不使用任务名模糊匹配或停止企微机器人。
